# Localization

## Follow the project's string system

| Found | Do |
|---|---|
| `.xcstrings` (String Catalog) | Edit catalog. SwiftUI `Text("key")` literals auto-extracted — keep literals or `String(localized:)`, never bypass catalog. |
| `Localizable.strings` / `.stringsdict` | Edit every `*.lproj` file holding key. |
| i18n JSON / YAML (`i18next`, `react-intl`, `vue-i18n`, `next-intl`) | Edit each locale file. Keep ICU plural/select syntax intact. |
| `res/values*/strings.xml` | Edit each `values-xx` file. Keep `plurals` and format args. |
| Hardcoded strings, no system | Edit inline. Never introduce i18n system. |

Never hardcode string in view when project has catalog.

## Languages

- **Source language** (first in `languages`, or catalog's source): rewrite with ladder.
- **Each other existing language**: write **native** version (`native.md`) — not translation of new source string. Then mark for review:
  - `.xcstrings` → localization `state` = `needs_review`.
  - Other formats (no state field) → list keys in `NOTES:` (implementer), so report names them as to review.
- Never add language that doesn't exist yet.

## Keys

- **Semantic keys** (`delete.confirm.title`): keep key, change values.
- **Source-text keys** (SwiftUI default, English text *is* key): changing text changes key, orphans existing translations. Never rename silently:
  - Strings just created → fine.
  - Existing ones → leave them, unless task asks for rename; then migrate (new key + carried/rewritten translations + old key removed).
- **Removed string** (rung 1): key becomes unused. Removing it from catalogs = structural change → only when task asks; else say it in `NOTES:`. Check key unused elsewhere before removing.

## Format arguments and plurals

- Keep every placeholder (`%@`, `%lld`, `{count}`, `%1$s`) and its order constraints.
- **Never add placeholder call site doesn't pass.** "Delete “{name}”?" is better copy, but key without `{name}` → UI prints braces. Propose as structural change (key + call site), never slip it into value.
- Real plural rules (`.stringsdict`, catalog variations, ICU `plural`), never "photo(s)".
- SwiftUI inline `^[\(n) photo](inflect: true)` inflects noun only, not verbs or adjectives around it. Use only when nothing else agrees ("12 photos"). Verb agreeing with count ("will be/is", French "sera/seront") → catalog plural variations, full sentences.
- Rewording pluralized string → rewrite every plural form in every language.
- Formatters (`Date.FormatStyle`, `Intl`, `NumberFormat`) over words in strings for dates, numbers, prices, durations.
