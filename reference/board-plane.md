## Plane board

`backlog.provider: plane` — **experimental**. Tickets = work items of self-hosted Plane Community Edition project; code, branches, PRs, claims stay on GitHub (`vcs.provider: github`). Code-host part (backlog script, `BOARD.md`, task file, claims, rounds, PRs): **reference/code-github.md**.

- **No `{backlog}` file, no local mirror.** Board = Plane project. Never write order, state, title into any file.
- **Ticket id = work item key** (**reference/code-github.md**, *Ticket id*): `<id>` = `<#id>` = `WA-42` — project identifier + sequence number, as Plane UI shows it, never `#WA-42`. Branch `wa/WA-42-login-apple`, task file `{tasks}/WA-42-login-apple.md`, claim ref `refs/wa-claims/WA-42/coding`. Bare number (`42`) or other project's key → script exit 2: ask user for full key.
- **Spec in task file only.** Spec written in card description never moves ticket to `grilled` (no hook sees it) — grill writes task file on ticket branch as usual.
- **Priority = Plane `sort_order`**, one order over whole board (each column shows its slice). Humans drag cards in Plane, `list` returns that order; `move` writes same value UI drag would.
- **No size.** Plane CE can't create estimates over its API: `size` null in rows, `set-field size` exit 2, `create` drops `--size` with note. Never ask user for size here.
- **Canceled = Canceled column** (`not_planned: true`), set by `cancel <id> --reason` on user's yes. Label `wa-ignore` = not a ticket (`get` exit 4).
- **Sprint = parent work item + cycle** — root labeled `wa-sprint` (not a ticket: `list` skips it, `get`/`claim` exit 4; keeps its column, Plane has no off-board), tickets = its children, mirrored in cycle of same name (Plane's sprint view, no dates). `split <id>` makes ticket root of own sprint + creates cycle; `create --sprint` / `set-field <id> sprint <name>` sets parent and cycle (root and cycle created on first use), `""` detaches both. Truth = parent: card dropped in cycle by hand without parent → not in sprint. Ticket under non-sprint parent → exit 4: never detach human's hierarchy. Root never closes on its own (PR hooks not built yet).
- **Milestone = Plane module** — humans create modules in Plane (never agent); highest = version order of names, as GitHub (**reference/milestones.md**). One per ticket: `set-field <id> milestone` / `create --milestone` puts card in that module, out of every other. `close-milestone` (`/wa-release` only) sets module `completed`; `completed` / `cancelled` module = closed. Plane paid Milestones never used.
- **Dependencies = Plane relations** (*blocked by*), `depend` / `get` → `blocked_by` as GitHub. Blocker open until its card sits in Done or Canceled. Add-only: dependency added by mistake → user removes it in Plane UI, never worked around.
- **Settings** — repo variables `WA_PLANE_URL`, `WA_PLANE_WORKSPACE`, `WA_PLANE_PROJECT_ID`, `WA_PLANE_STATES` (state ids), written by `provision` (also turns on project's cycles and modules). API key: env `PLANE_API_KEY` for agents, Actions secret `WA_PLANE_API_KEY` for hooks — never in repo, config or chat. Script says `PLANE_API_KEY not set` → ask user to export it in their shell, stop.
- **Rate limit** — server must run `API_KEY_RATE_LIMIT=1000000/second` (Plane default 60/min per key). Script prints `Plane rate limit hit` → it retries alone; tell user to lift limit on server.
- **Ticket branch = plain branch** — no GitHub issue to link: wherever a skill says `gh issue develop <id> --name <branch> --base <fork point> --checkout`, run `git switch -c <branch.prefix><id>-<slug> origin/<fork point>` + `git push -u origin <branch>` right away (worktree: `git worktree add -b <branch> {worktrees}/<id>-<slug> origin/<fork point>`, push from there). No Development link: branch name alone ties branch to card.
- **Claims** — same verbs, refs, exit codes as **reference/code-github.md**, *Claim, reservation*. Winning claim moves card to `grilling` / `coding` (priority kept), assigns Plane user owning API key, comments on card. Reservation compares user ids; `@<login>` (exit 3 with `assigned: true`, `whoami` → `login`) = Plane display name, maybe shared by two users; GitHub account writing refs, branches, PRs = `whoami` → `vcs_login`.
- **Hooks** — caller `.github/workflows/whackagent-board-plane.yml` runs whackagent `board-plane.yml@hooks-v2` → `wa-backlog hook` on self-hosted runner next to Plane, label = repo variable `WA_RUNNER_LABEL` (default `self-hosted`). Built: task file with non-empty `## Acceptance criteria` pushed on ticket branch → `grilled` (from `todo` / `grilling`), grilling claim dropped, ✅ comment on card. Spec in card description moves nothing (*Spec in task file only*).
  - **Confirm after grill push** — re-read `get <id>` every ~15 s, up to ~2 min (runner online: seconds). Still `grilling` → `gh run list --workflow whackagent-board-plane.yml --branch <branch> --limit 3 --json status,conclusion,event,url,headSha` → tell user which: failed (run URL, log names cause), queued (no runner labeled `WA_RUNNER_LABEL` online: start it; URL), in progress (URL), none (`not triggered`: caller missing on branch's fork point, or `branches:` filter ≠ prefix). Never set state, never release to fake `grilled`: hooks own it — user fixes, re-runs (`gh run rerun <id>`) or pushes again.
  - **PR hooks not built yet** — `review`, `done`, closed-unmerged → `grilled` never move on their own. Round needing them (coding round: `/wa-code`, `/wa-autopilot` coding, `/wa-feedback`, `/wa-validate`, `/wa-close`) → stop before claim: say `PR hooks not built yet on Plane — card stays grilled`, stop.
- **Not built yet** (experimental): `link-pr`, PR hooks, board check, `BOARD.md` Plane section. Verb exits 2 `not built yet on a Plane board` → say so, stop. Never work around it: no card moved by hand in Plane on agent's behalf.
