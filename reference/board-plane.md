## Plane board

`backlog.provider: plane` — **experimental**. Tickets = work items of self-hosted Plane Community Edition project; code, branches, PRs, claims stay on GitHub (`vcs.provider: github`). Code-host part (backlog script, `BOARD.md`, task file, claims, rounds, PRs): **reference/code-github.md**. Worker rules of this board: **BOARD.md → This board: Plane** — bullets below = whackagent's way of meeting them.

- **No `{backlog}` file, no local mirror.** Board = Plane project. Never write order, state, title into any file.
- **Ticket id = work item key** (**reference/code-github.md**, *Ticket id*): `<id>` = `<#id>` = `WA-42` — project identifier + sequence number, as Plane UI shows it, never `#WA-42`. Branch `wa/WA-42-login-apple`, task file `{tasks}/WA-42-login-apple.md`, claim ref `refs/wa-claims/WA-42/coding`. Bare number (`42`) or other project's key → script exit 2: ask user for full key.
- **Spec in task file only** (**BOARD.md → This board: Plane**, *Spec*) — grill writes task file on ticket branch as usual; card description never moves ticket.
- **Priority = Plane `sort_order`**, one order over whole board (each column shows its slice). Humans drag cards in Plane, `list` returns that order; `move` writes same value UI drag would.
- **No size.** Plane CE can't create estimates over its API: `size` null in rows, `set-field size` exit 2, `create` drops `--size` with note. Never ask user for size here.
- **Canceled = Canceled column** (`not_planned: true`), set by `cancel <id> --reason` on user's yes. Label `wa-ignore` = not a ticket (`get` exit 4).
- **Sprint = parent work item + cycle** (**BOARD.md → This board: Plane**, *Sprints*) — root labeled `wa-sprint` (not a ticket: `list` skips it, `get`/`claim` exit 4; keeps its column, Plane has no off-board), tickets = its children, mirrored in cycle of same name (Plane's sprint view, no dates). `split <id>` makes ticket root of own sprint + creates cycle; `create --sprint` / `set-field <id> sprint <name>` sets parent and cycle (root and cycle created on first use), `""` detaches both. Ticket under non-sprint parent → exit 4: never detach human's hierarchy. Hooks close root (→ Done) when sprint lands: sprint branch PR merged; no sprint branch → last child landed. Root left open with nothing to land (`/wa-close <sprint>` step 3; all children canceled) → no verb closes it: tell user to move root card to Done (Canceled when nothing shipped) in Plane.
- **Milestone = Plane module** — humans create modules in Plane (never agent); highest = version order of names, as GitHub (**reference/milestones.md**). One per ticket: `set-field <id> milestone` / `create --milestone` puts card in that module, out of every other. `close-milestone` (`/wa-release` only) sets module `completed`; `completed` / `cancelled` module = closed. Plane paid Milestones never used.
- **Dependencies = Plane relations** (*blocked by*), `depend` / `get` → `blocked_by` as GitHub. Blocker open until its card sits in Done or Canceled. Add-only: dependency added by mistake → user removes it in Plane UI, never worked around.
- **Settings** — repo variables `WA_PLANE_URL`, `WA_PLANE_WORKSPACE`, `WA_PLANE_PROJECT_ID`, `WA_PLANE_STATES` (state ids), written by `provision` (also turns on project's cycles and modules). API key: env `PLANE_API_KEY` for agents, Actions secret `WA_PLANE_API_KEY` for hooks — never in repo, config or chat. Script says `PLANE_API_KEY not set` → ask user to export it in their shell, stop.
- **Rate limit** — server must run `API_KEY_RATE_LIMIT=1000000/second` (Plane default 60/min per key). Script prints `Plane rate limit hit` → it retries alone; tell user to lift limit on server.
- **Ticket branch = plain branch** — no GitHub issue to link: wherever a skill says `gh issue develop <id> --name <branch> --base <fork point> --checkout`, run `git switch -c <branch.prefix><id>-<slug> origin/<fork point>` + `git push -u origin <branch>` right away (worktree: `git worktree add -b <branch> {worktrees}/<id>-<slug> origin/<fork point>`, push from there). No Development link: branch name ties branch to card, hook links PR (*PR link*).
- **Claims** — same verbs, refs, exit codes as **reference/code-github.md**, *Claim, reservation*. Winning claim moves card to `grilling` / `coding` (priority kept), assigns Plane user owning API key, comments on card. Reservation compares user ids; `@<login>` (exit 3 with `assigned: true`, `whoami` → `login`) = Plane display name, maybe shared by two users; GitHub account writing refs, branches, PRs = `whoami` → `vcs_login`.
- **PR link** (**BOARD.md → This board: Plane**, *Ticket link*) — where GitHub board writes `Closes <#id>` (PR body, `## Ticket`: **reference/pull-requests.md**), Plane writes card link `[<#id>](<ticket url>)` (`get <id>` → `url`, `<WA_PLANE_URL>/<workspace>/browse/WA-42/`), never `Closes`, never `#WA-42`. Hook finds ticket from branch `<branch.prefix><id>-<slug>`, else from that one card link in body (PR on another branch, e.g. cloud agent's), and adds PR as link on card: never link by hand. `wa-backlog link-pr <id> <pr>` = repair only. PR linking two cards → hook moves nothing, reports on PR.
- **Hooks** — caller `.github/workflows/whackagent-board-plane.yml` runs whackagent `board-plane.yml@hooks-v2` → `wa-backlog hook` on self-hosted runner next to Plane, label = repo variable `WA_RUNNER_LABEL` (default `self-hosted`). Same rules as GitHub board (**reference/code-github.md**, *States*, *Agent round*): task file with non-empty `## Acceptance criteria` pushed on ticket branch → `grilled` (from `todo` / `grilling`, grilling claim dropped); PR opened → `review`, round pushed to PR → `review`, claim dropped; ready → ✅ comment; merged → `done` (run report posted on card); closed unmerged → `grilled` (unless coding claim or other open PR); sprint landing per *Sprint*. Spec in card description moves nothing (*Spec in task file only*).
  - **Board check** — schedule (weekdays) or manual run (`gh workflow run whackagent-board-plane.yml`): report-only, never moves card. Problems: **BOARD.md → This board: Plane**, *Checks*. One `⚠️ board check` comment per problem on card, never twice; flipped to `✅ resolved` once fixed; list in run's job summary. Comment = fix it yourself (claim, release, open PR) or tell user; never answer it by moving card by hand.
  - **Confirm card moved** — after every push or PR action hook acts on (grill push → `grilled`, round push / draft PR → `review`, merge → `done`): re-read `get <id>` every ~15 s, up to ~3 min (runner online: seconds). Not moved → `gh run list --workflow whackagent-board-plane.yml --branch <branch> --limit 3 --json status,conclusion,event,url,headSha` → tell user which: failed (run URL, log names cause — `WA_PLANE_URL` / `WA_PLANE_API_KEY` missing included), queued (no runner labeled `WA_RUNNER_LABEL` online: start it; URL), in progress (URL), success (run summary line names why nothing moved, e.g. card in column whackagent doesn't own; URL), none (`not triggered`: caller missing on branch's fork point / PR base, `branches:` filter ≠ prefix, or PR `CONFLICTING` — **reference/code-github.md**, *Agent round*). Never set state, never release to fake the move: hooks own it — user fixes, re-runs (`gh run rerun <id>`) or pushes again.
- **Single writer** (**BOARD.md → This board: Plane**, *Single writer and runner*) — Plane's own GitHub integration stays off; `/wa-setup` checks it (`wa-backlog check-integration` → `github_integration` `off` / `on` / `unknown`). Card moved with no hook run behind it → tell user to run that check, never move card back by hand.
- **Not built yet** (experimental): spec in card description moving card to `grilled` (needs webhook relay), size. Asked for → say so. Never work around it: no card moved by hand in Plane on agent's behalf.
